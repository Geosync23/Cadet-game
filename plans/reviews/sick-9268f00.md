# Re-check: the sickness fixes (claude/leave 9268f00, 0.61.8)

Reviewer 1d, 2026-10-17. This re-checks the fixes for sick-b0c0f37.md's three lows.

## Verdict: PASS WITH FIXES (one MEDIUM regression, a one-line fix)

The three lows are fixed as proposed:
1. **The exact refund.** `careerMissed` keeps what the miss took (`c.mx`), and a sick note restores exactly that.
2. **Sick days vary by game.** The roll is seeded with `SICK.seed ^ socHash(SHIP.player.name)`, the name you sign on the manifest.
3. **A walking floor.** Walking never drops below 0.35 while sick (`SICK.floor`).

## MEDIUM (regression): the first missed-shift warning is gone
`careerMissed` (starship-cadet.html line 27169 in 9268f00) now reads:

```
const c = careerInit(); c.md = d; c.mx = Math.round(...) / 100;   // what it took, so a sick note gives back exactly that if (!(c.k & 2)) { c.k |= 2; careerTip('missed'); }
```

The old `if (!(c.k & 2)) { c.k |= 2; careerTip('missed'); }` was pasted after the new comment, so it is now part of the comment and never runs.
- The first missed shift no longer shows its warning tip (`career.tip.missed`). That tip shows even with tips off, and it's the first of the design's "plenty of warning".
- `k & 2` is never set either.
- leave_check doesn't test that tip, so it still says OK.

**Fix:** move the `if` before the comment:

```
c.mx = Math.round((w0 - careerWork()) * 100) / 100; if (!(c.k & 2)) { c.k |= 2; careerTip('missed'); }   // mx: what it took...
```

Worth adding to leave_check: after the first miss, `SHIP.career.k & 2` is set.
