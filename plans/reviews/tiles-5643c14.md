draws from a mulberry32 stream seeded by schedU (keys 800-807 listed, 808-829 free). There is no top-level TILES, and
the TL_ / tiles* names clash with nothing. TL_STYLE's `rina` and `tomas` are real roster ids. It sits before section 6

1. **LOW-MEDIUM, the gate gets looser with fewer games:** the first-player test passes when the 95% band *reaches*
   48-52%, so the fewer games, the wider the band and the easier the pass. Hard at 45.5% over 750 games passes, though
   the page says Hard is 50.7%. With a fixed seed the numbers are reproducible, so please (a) report the default-run
   numbers (4,000 / 2,000) in DEV_NOTES and the page, and (b) have the gate refuse to judge balance below the default
   count (or use a fixed tolerance at the default count). If Hard really leans to the second player (here 45.5%, and
   tie-breaks 86 / 125), the page's "no first-player advantage" line should say so.
2. **LOW:** the quick game's tie-break leans hard to seat 0 at Medium and Hard (134 / 37, 97 / 49). Totals stay
   balanced, but the "whoever reached first" tie rule plainly favours the first player. It's worth one sentence in
   the plan's Decided section.
3. **NOTE:** the deal draws each mark at random (`rng()*3`), not a 4/4/4 set, so a side can get, say, 7 Stars. That's
   fair because it's mirrored, but it's different from how the page describes the marks ("shuffled"). The balance runs
   use the same deal, so the numbers stand.

## Addendum: 32ed900 (0.46.1, the board on the device): PASS WITH ONE FIX
Fine:
- The board is a persistent element in the device's `dom` block. Buttons are reused, and each square is at least
  44 px with an aria-label ("c4: their Star, move here, docks").
- Reduced motion turns the effects off, and every move also writes a line, so nothing happens only as a picture.
- The CSS is injected once; there are no new three.js draw calls.
- The device redraws dom views each ship minute. That's cheap here, since only the tile glyphs inside the buttons are
  rebuilt.
- tilesNew's `first` seat and the equal-turns rule follow whoever went first.
- `simNote('tiles')` goes on the bus, and SHIP.tiles is a stub until 0.46.2's save.

1. **LOW-MEDIUM (determinism):** tilesTalk picks its stand-in lines with `G.rng`, the same stream the crew's moves
   use. So whether a talk line is drawn (whether lineFor has a writer's line, the chatty miss line, a dock line) shifts
   every later AI choice. The same save and seed will play differently once the writers' `tiles.*` lines land, or
   after any content change. Give talk its own stream (`schedU(..., 807)`, as the section's key list already says) or
   a second tilesRng.
2. LOW: the TL_TALK stand-ins are hard-coded text that lines_check never sees. That's fine as stand-ins, but they
   should move to `content/` (kind `tiles.*`) before release.

## Addendum: acb9bc8 (0.46.2, sitting down to play, rewards, the save): PASS WITH ONE FIX
Fine:
- save.tiles is read defensively (counts must be finite and >= 0, vs pairs checked, days or null) and saved through
  SAVE_EXTRA; New game resets it.
- Walking away leaves the game without counting it. tilesWorldTap returns false when nobody is there, so you sit as
  before.
- relAdd, memAdd and newsAdd are typeof-guarded.

1. **MEDIUM (friendship farming):** tilesReward gives `relAdd(opp, 'tiles', 2 or 3)` for *every* game, with no daily
   limit. A chat gives 2 once a day (`r.chatDay`). A quick game takes about 2 real minutes, so ten games with Tomas in
   one evening is 20-30 points (REL_TIERS 10/30/60: stranger to colleague in one evening, past every other route).
   Give the friendship once per opponent per ship day (like chatDay), and keep later games for fun, the tally and the
   social need. `memAdd(opp, 'came.tiles')` likewise only needs to happen once a day.
2. **NOTE for the lead:** interactions_check's three Deck 4 Tiles-table rows now fail by design (the engineer
   reported this). Don't combine it red: either interactions_check's expectations are updated in the same combine, or
   tilesWorldTap leaves Deck 4's lounge tables to ixLounge outside Tiles night.
