# Preview shots (build 0.91.0, claude/integration)

Taken for the magazine-style preview. Phone shots are 390x844 at 3x (1170x2532); desktop shots are 1280x800 at 2x (2560x1600). Taken headless in Chromium (software WebGL) with Dev mode used only to move the clock and the player; Dev mode's own tag, the TIP box and the toast are hidden. The normal game HUD is left in. Saved as JPEG at quality 88 (the repo ignores .png files).
