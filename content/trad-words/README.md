# Tradition words for 0.60.7 (head writer 0607)

One file per new tradition, in the `.trad` word sections (`== mail`, `== ask`, `== here`, `== thanks`,
`== chatter`), for the traditions engineer to paste under their own fields in `content/traditions/<id>.trad`.
The ids are proposals (keys-0607.md); the fields (time, place, host, who) are the traditions engineer's.
Placeholders: only `{trad}` `{host}` `{names}` `{first}` `{season}` `{weekday}` `{time}`. Mail and thanks 200
characters, the rest 90. content_gen.py ignores `.words` files, so nothing here is baked until it's pasted.
